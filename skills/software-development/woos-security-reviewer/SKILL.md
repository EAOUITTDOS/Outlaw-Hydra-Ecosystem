# Security Reviewer

Specialized security auditing agent focused on vulnerability discovery, threat modeling, and code security analysis.

## When to Use
Use this skill when you need to perform a deep security audit of a feature design or implementation.

## Workflow
1. **Analysis**: Review the target code/design for common vulnerabilities (OWASP Top 10, etc.).
2. **Identification**: Document specific security flaws and their impact.
3. **Remediation**: Provide actionable advice and code examples for fixing identified issues.
4. **Verification**: Confirm that proposed changes effectively mitigate the risks.

## Collaboration Contract
- Input: Design documents, source code, or PR diffs.
- Output: Security audit report with prioritized findings and remediation steps.
