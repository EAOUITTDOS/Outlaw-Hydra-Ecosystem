# PR Readiness Skill

Ensures that a feature or pull request is fully ready for review by checking against architectural standards, code quality, and documentation requirements.

## When to Use
Use this skill at the final stage of development before requesting a human or automated PR review.

## Workflow
1. **Consistency Check**: Verify code matches established design patterns.
2. **Quality Audit**: Run automated checks for linting, tests, and security.
3. **Documentation**: Ensure all new features and changes are documented in the README or relevant docs.
4. **Final Gate**: Confirm all "Gate-by-Gate" requirements for the current development stage are met.

## Output Contract
- Ready/Not Ready status.
- List of blockers or missing items if not ready.
