# Security Review Skill (ECC)

Expert security analysis for systems architecture and implementation.

## Focus Areas
1. **Threat Modeling**: Identify potential threat actors and attack vectors.
2. **Architecture Audit**: Review system design for security flaws (e.g., insecure defaults, lack of encryption).
3. **Control Validation**: Ensure proper authentication, authorization, and accounting (AAA) are in place.
4. **Risk Assessment**: Quantify the risk of identified issues.

## Workflow
- **Input**: Architecture diagrams, implementation specs, or security requirements.
- **Output**: Risk matrix and prioritized remediation plan.
